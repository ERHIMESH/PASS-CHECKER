✨ Neon Password Pro

A modern, interactive, and visually stunning Password Strength Checker built with Python and Tkinter. Designed with a dark neon aesthetic, this application provides real-time, lag-free feedback on your password's security and includes a built-in generator for highly secure passwords.

🚀 Key Features

*   🎨 Modern Dark UI: Dracula-inspired neon color palette (`#1E1E2F` background with vibrant cyan, red, yellow, and green accents).
*   ⚡ Zero-Lag Validation: Uses real-time `<KeyRelease>` event binding to instantly evaluate password strength as you type.
*   🎲 One-Click Password Generator: Automatically generates a cryptographically strong 12-character password mixing letters, numbers, and symbols.
*   👁️ Show/Hide Functionality: Seamlessly toggle password visibility with a clean UI checkbox.
*   ✨ Interactive UX: Smooth hover animations on buttons and flat, borderless input fields for a premium feel.

🛠️ Tech Stack

*   Python 3.14.4
*   Tkinter** (Standard GUI Library)
    Regex (`re`)** (For advanced pattern matching)

💡 How It Works
*   Weak: Less than 8 characters, or missing numbers/letters. (Alerts in Neon Red)
*   Medium: Meets basic criteria but lacks special characters. (Alerts in Neon Yellow)
*   Strong: 8+ characters, contains letters, numbers, and special symbols! (Alerts in Neon Green)
